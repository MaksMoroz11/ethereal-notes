# Frontend

React, Vite, React Router, Zustand и Tiptap. Интерфейс сохраняет общий стиль сайта; доступ проверяется и клиентом, и API.

## Запуск

Нужны Node.js 22.12+ (в CI — 24) и pnpm версии из `package.json`.

```bash
cd frontend
pnpm install --frozen-lockfile
pnpm dev
```

API по умолчанию доступен через `/api` на том же адресе, что и сайт. Vite проксирует эти запросы на `http://127.0.0.1:8000`, а Docker — на сервис backend. Локально можно открывать `localhost` или `127.0.0.1`: cookie остаётся на выбранном адресе. В HTTPS-конфигурации также используется `/api`.

Если в старом `.env` задан `VITE_API_URL=http://localhost:8000` или `http://127.0.0.1:8000`, замените его на `/api` и пересоберите frontend. Явный адрес отдельного API по-прежнему поддерживается, но frontend и API должны находиться на одном сайте для SameSite-cookie.

```bash
pnpm lint
pnpm test
pnpm build
```

## Состояние и обновление

`shared/store` содержит существующие Zustand stores. Компоненты подписываются на отдельные данные и действия. `reconcile` сохраняет ссылки на неизменившиеся объекты; колонки и карточки мемоизированы. Операции с колонками обновляют текущую доску; сложное удаление загружает одну затронутую доску.

`FolderTree` поддерживает перетаскивание между папками и в корень, подсветку назначения, раскрытие закрытой папки через 600 мс и прокрутку у края списка. `Dashboard` перемещает задачи между колонками через существующий endpoint с проверкой прав и ревизии. Пока запрос выполняется, повторный перенос заблокирован; ошибка сохраняет прежнее положение. Выбор через меню доступен для клавиатуры и сенсорного экрана.

Новые колонки появляются с анимацией. `KanbanLayout` измеряет высоту колонок и анимирует изменение их положения через Web Animations, сохраняя DOM существующих колонок. `prefers-reduced-motion` отключает эти эффекты. Форма создания блокирует повторные запросы и сохраняет название при ошибке.

`shared/lib/workspaceSync.js` сверяет идентификаторы и ревизии через `/workspaces/{id}/sync` раз в 10 секунд. Документы с конфликтом сохраняют черновик и предлагают серверную редакцию или явное сохранение своего текста. Смена пространства, фильтра и сессии защищена от запоздалых ответов.

Токен сессии недоступен JavaScript. `shared/api/client.js` отправляет cookie через credentials и CSRF-заголовок. При запуске проверяются `/auth/me` и `/auth/csrf`. `authStore` синхронизирует вход/выход вкладок через сигнал localStorage без токена.

До ответа сервера шапка показывает «Проверка сессии…», а не ссылку входа. Возвращение на вкладку и восстановление соединения повторно проверяют cookie; подтверждение того же аккаунта не очищает пространство и черновики. Перед входом или регистрацией проверяется актуальная сессия. Ответы API и index.html не кешируются.

Режим формы задаёт `mode=register` в адресе страницы. Согласие, запоминание входа и автосохранение используют общий `components/ui/checkbox.jsx` с фиксированным размером, рамкой и отметкой в обеих темах.

## Где редактировать тексты

В `src/shared/messages` находятся тематические словари `auth`, `tasks`, `documents`, `workspaces`, `notifications`, `errors`. Общие подписи ролей и действий находятся в `workspaces.js`; коды ошибок соответствуют backend. Неизвестная ошибка использует detail и резервный текст. Конфигурация API хранится в окружении отдельно от текстов.

`public/robots.txt` копируется Vite в сборку. `public/screenshots` содержит реальные снимки для `/documentation`, исходники снимков и подписи — в `../docs`.
