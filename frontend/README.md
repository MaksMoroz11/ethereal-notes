# Frontend

Клиентская часть Ethereal на React, Vite, React Router и Zustand.

## Что умеет

- вход и регистрация;
- переключение рабочих пространств;
- управление пространствами и участниками с учётом ролей;
- канбан-доски и задачи;
- редактор документов с форматированием;
- история версий и восстановление документа;
- журнал действий пространства.

## Запуск

1. Установить Node.js и pnpm.
2. Выполнить `pnpm install` в папке `frontend`.
3. При необходимости задать `VITE_API_URL` адресом API. По умолчанию используется `http://127.0.0.1:8000`.
4. Запустить режим разработки: `pnpm dev`.

Production-сборка: `pnpm build`

Проверка стиля: `pnpm lint`
